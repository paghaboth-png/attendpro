# ការណែនាំអំពីការ Backup និងស្តារទិន្នន័យ (Database Backup & Restore Guide)

ឯកសារនេះត្រូវបានរៀបចំឡើងជាពិសេសសម្រាប់ **ម្ចាស់ហាង (Store Owner)** ដើម្បីគ្រប់គ្រងសុវត្ថិភាពទិន្នន័យរបស់ប្រព័ន្ធ AttendPro យ៉ាងងាយស្រួល និងមានប្រសិទ្ធភាពខ្ពស់។

---

## ១. យន្តការការពារទិន្នន័យដោយស្វ័យប្រវត្តិ (Neon Cloud Database)

ប្រព័ន្ធ AttendPro ប្រើប្រាស់សេវាកម្ម Cloud PostgreSQL របស់ **Neon (neon.tech)** ដែលមានមុខងារការពារទិន្នន័យដោយស្វ័យប្រវត្តិកម្រិតខ្ពស់បំផុត៖

1. **Point-In-Time Restore (PITR) រយៈពេល ៧ ថ្ងៃ (7-Day Retention)**
   - Neon រក្សាទុកប្រវត្តិទិន្នន័យរាល់វិនាទីក្នុងរយៈពេល ៧ ថ្ងៃចុងក្រោយ។
   - ប្រសិនបើមានបញ្ហា ឬការលុបច្រឡំណាមួយ លោកអ្នកអាចត្រឡប់ទិន្នន័យទៅកាន់នាទីណាមួយក្នុងរយៈពេល ៧ ថ្ងៃកន្លងមកបានយ៉ាងងាយ។
2. **Branching (ការបង្កើតមែកធាងទិន្នន័យ / Instant Snapshot)**
   - មុនពេលធ្វើបច្ចុប្បន្នភាពធំ ឬមុនពេលសម្អាតទិន្នន័យ លោកអ្នកអាចចូលទៅកាន់ Neon Console (`console.neon.tech`) ហើយចុច **Create Branch**។
   - Branch ថ្មីបង្កើតឡើងភ្លាមៗក្នុងពេលត្រឹមតែ ១ វិនាទី ដោយផ្ទុកទិន្នន័យទាំងមូលដូចដើមបេះបិទ។

---

## ២. របៀប Backup ទិន្នន័យចេញពីផ្ទាំងគ្រប់គ្រង (Admin Settings)

លោកអ្នកមិនចាំបាច់ចេះសរសេរកូដឡើយ! នៅក្នុងប្រព័ន្ធ AttendPro មានមុខងារទាញយកទិន្នន័យដោយផ្ទាល់៖

1. ចូលទៅកាន់ម៉ឺនុយ **ការកំណត់ (Settings)** ➜ ផ្ទាំង **ការបម្រុងទុកទិន្នន័យ (Backup & Export)**
2. លោកអ្នកនឹងឃើញជម្រើស ២៖
   - **ទាញយកទិន្នន័យទាំងមូល (JSON Backup)**៖ ផ្ទុកទិន្នន័យតារាងទាំងអស់ (បុគ្គលិក, វត្តមាន, ប្រាក់ខែ, សាខា, វេនការងារ, Settings) សម្រាប់បម្រុងទុកសុវត្ថិភាព។
   - **ទាញយកទិន្នន័យវត្តមាន (CSV)**៖ ផ្ទុកទិន្នន័យ Check-in/Check-out ទាំងអស់សម្រាប់បើកមើលលើ Microsoft Excel។
3. ចុចប៊ូតុង **"ទាញយកទិន្នន័យ (Download)"** ហើយរក្សាទុកឯកសារនោះក្នុងកុំព្យូទ័រ ឬ Google Drive របស់លោកអ្នក។
4. **អនុសាសន៍**៖ គួរទាញយក Backup រៀងរាល់ចុងខែ ឬមុនពេលគណនាប្រាក់ខែបុគ្គលិក។

---

## ៣. របៀបស្តារទិន្នន័យឡើងវិញតាម Neon Console (Restore Procedure)

ក្នុងករណីមានអាសន្ន (ឧទាហរណ៍៖ ទិន្នន័យត្រូវបាត់បង់ ឬច្រឡំដៃលុបខុសធ្ងន់ធ្ងរ)៖

1. បើក Browser ចូលទៅកាន់ [https://console.neon.tech](https://console.neon.tech) ហើយចូល Login គណនី Neon របស់លោកអ្នក។
2. ជ្រើសរើស Project របស់ AttendPro។
3. ចូលទៅកាន់ផ្នែក **Branches**៖
   - ចុចលើមែកធាងចម្បង (`main`)។
   - ជ្រើសរើស **Time Travel / Restore** ឬបង្កើត Branch ថ្មីពីពេលវេលាមុនពេលមានបញ្ហា (Point in time)។
4. ភ្ជាប់ Connection String នៃ Branch ថ្មីទៅកាន់ Vercel Environment Variable `DATABASE_URL` (ប្រសិនបើចង់ប្តូរទៅកាន់ Branch នោះជាផ្លូវការ)។

## ៤. ការណែនាំស្តីពីការសម្អាតទិន្នន័យ (Data Cleanup Safety)

- **ទិន្នន័យបុគ្គលិកពិត និងវត្តមានជាក់ស្តែង** នឹងមិនត្រូវបានលុបដោយស្វ័យប្រវត្តិឡើយ។
- មុខងារ **"សម្អាតទិន្នន័យសាកល្បង"** នៅក្នុងទំព័រ Settings នឹងលុបតែគណនីបុគ្គលិកគំរូ (EMP001 - EMP010) ប៉ុណ្ណោះ ដោយរក្សាទុកគណនី Super Admin, សាខា, វេនការងារ, ថ្ងៃឈប់សម្រាក និងការកំណត់ផ្សេងៗទាំងអស់។
- **ត្រូវប្រាកដថាបានទាញយក JSON Backup មួយច្បាប់ទុកមុនជានិច្ច មុនពេលចុចសម្អាតទិន្នន័យ!**
