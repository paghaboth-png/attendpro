# បញ្ជីត្រួតពិនិត្យដំណើរការជាផ្លូវការ (AttendPro Go-Live Checklist)

ឯកសារនេះជាជំនួយដល់ **ម្ចាស់ហាង** ក្នុងការដាក់ឱ្យប្រព័ន្ធ AttendPro ដំណើរការជាក់ស្តែងជាមួយបុគ្គលិកពិតប្រាកដតាមលំដាប់លំដោយយ៉ាងត្រឹមត្រូវ និងមានសុវត្ថិភាពខ្ពស់បំផុត។

---

### ☐ ជំហានទី ១៖ ទាញយក Backup ដំបូងរក្សាទុក (Initial Backup Download)
1. ចូលទៅកាន់ **ការកំណត់ (Settings)** ➜ **ការបម្រុងទុកទិន្នន័យ (Backup & Export)**
2. ចុចទាញយក **JSON Backup** មួយច្បាប់រក្សាទុកក្នុងកុំព្យូទ័រ ឬ Google Drive ផ្ទាល់ខ្លួន។

---

### ☐ ជំហានទី ២៖ បង្កើត និងរក្សាទុកកូដស្តារគណនី (Super Admin Recovery Codes)
1. នៅក្នុងទំព័រ **ការកំណត់ (Settings)** ➜ ស្វែងរកកាត **"កូដស្តារគណនី Super Admin"**
2. ចុចប៊ូតុង **"បង្កើតកូដស្តារថ្មី (៨ កូដ)"**
3. ចុច **ចម្លង (Copy)** ឬ **បោះពុម្ព (Print)** រក្សាទុកកូដទាំង ៨ នេះនៅកន្លែងសម្ងាត់ និងមានសុវត្ថិភាពខ្ពស់ (សម្រាប់ប្រើប្រាស់ពេលភ្លេចលេខសម្ងាត់ ឬបាត់លេខទូរស័ព្ទ)។

---

### ☐ ជំហានទី ៣៖ សម្អាតទិន្នន័យសាកល្បង (Clean Up Demo Data)
1. នៅក្នុងទំព័រ **ការកំណត់ (Settings)** ➜ ស្វែងរកកាត **"សម្អាតទិន្នន័យសាកល្បង (Clean Up Demo Data)"**
2. ចុចប៊ូតុង **"សម្អាតទិន្នន័យសាកល្បង"**
3. ពិនិត្យមើលចំនួនទិន្នន័យសាកល្បង (EMP001-EMP010 នឹងត្រូវលុប រីឯគណនី Super Admin, សាខា, វេនការងារ, Settings ត្រូវបានរក្សាទុក)
4. វាយពាក្យបញ្ជាក់ជាអក្សរខ្មែរថា **"លុប"** រួចចុច **"បញ្ជាក់ការលុបជាស្ថាពរ"**។

---

### ☐ ជំហានទី ៤៖ នាំចូលទិន្នន័យបុគ្គលិកពិតពី Excel (Import Real Employees)
1. ចូលទៅកាន់ទំព័រ **បុគ្គលិក (Employees)**
2. ចុចប៊ូតុង **"ទម្រង់គំរូ (Template)"** ដើម្បីទាញយកឯកសារ Excel គំរូ
3. បើកឯកសារ Excel បំពេញព័ត៌មានបុគ្គលិកពិតរបស់ហាង (ឈ្មោះ, លេខទូរស័ព្ទ, ផ្នែក, តួនាទី, ប្រាក់ខែ, វេនការងារ) រួច Save
4. ត្រឡប់មកទំព័របុគ្គលិកវិញ ចុចប៊ូតុង **"នាំចូល Excel (Import Excel)"** ហើយជ្រើសរើសឯកសារ Excel នោះ
5. ប្រព័ន្ធនឹងបង្កើតគណនីបុគ្គលិកទាំងអស់ដោយស្វ័យប្រវត្តិ ព្រមទាំងផ្តល់ឯកសារ CSV នៃ Username/Password សម្រាប់ទាញយកភ្លាមៗ។

---

### ☐ ជំហានទី ៥៖ ចែករំលែកគណនីដល់បុគ្គលិក (Distribute Credentials)
1. ចែករំលែក Username និង Password ឬលេខ PIN ទៅកាន់បុគ្គលិកម្នាក់ៗ
2. បុគ្គលិកអាច Login ចូលប្រើប្រព័ន្ធបានភ្លាមៗ ដោយមិនមានការបង្ខំឱ្យប្តូរពាក្យសម្ងាត់ឡើយ (ឬអាចប្តូរតាមចិត្តបានក្នុង Profile)។

---

### ☐ ជំហានទី ៦៖ បោះពុម្ព QR Code Check-in សម្រាប់សាខា (Print Branch QR Codes)
1. ចូលទៅកាន់ទំព័រ **សាខា (Branches)**
2. ចុចលើប៊ូតុង QR Code នៃសាខានីមួយៗ
3. ចុចបោះពុម្ព **Poster A4** ដើម្បីយកទៅបិទលើជញ្ជាំងក្បែរច្រកចេញចូល ឬបើកទំព័រ QR Code លើ iPad/Tablet សម្រាប់បុគ្គលិកស្កេន។

---

### ☐ ជំហានទី ៧៖ បិទគណនីសាកល្បងជាស្ថាពរ (Disable Demo Accounts)
1. ចូលទៅកាន់ **ការកំណត់ (Settings)** ➜ ស្វែងរកកាត **"គណនីសាកល្បង (Demo Accounts)"**
2. ចុចបិទ Switch **"អនុញ្ញាតឱ្យ Login ដោយគណនី Demo"**
3. ចាប់ពីពេលនេះតទៅ មានតែបុគ្គលិកពិត និង Admin ពិតប៉ុណ្ណោះដែលអាច Login ចូលប្រើប្រព័ន្ធបាន។

---

### ☐ ជំហានទី ៨ (បន្ថែម - ស្រេចចិត្ត)៖ ភ្ជាប់ឈ្មោះ Domain ផ្ទាល់ខ្លួន (Custom Domain)
- ប្រសិនបើលោកអ្នកមាន Domain ផ្ទាល់ខ្លួន (ឧ. `attend.mystore.com`) សូមអនុវត្តតាមការណែនាំក្នុងឯកសារ `docs/custom-domain-guide.md`។
